Input File Format — Shopsy Excel

Upload karne se pehle check karo ki aapki .xlsx/.xls file mein ye columns hain (header names is tarah se ya milte-julte case-insensitive hone chahiye):
Shopsy Column Status Maps To / Used For
Order IdRequiredZoho "Sales order id"
SKU CodeRequiredZoho "SKU"
ProductRequiredZoho "Item Name"
Invoice Date (mm/dd/yy)RequiredZoho "Invoice Date" & "Due Date"
QuantityRequiredZoho "Quantity" (direct copy)
Invoice AmountRequiredMultiplied by Quantity → Zoho "Item Price"
Ship to nameRequiredCombined with Phone → "Customer Name"
Phone NoRequiredCombined with name → "Customer Name", "MOBILE NO"
StateRequiredDecides "Place of Supply" & GST18/IGST18
CGSTOptionalIf present & non-zero → forces GST18 (CGST+SGST)
IGSTOptionalRead but tax type mainly decided by State/CGST
Customer GSTINOptional"GST Identification Number (GSTIN)" + GST Treatment
Address Line 1 / 2OptionalBilling & Shipping address fields
CityOptionalBilling & Shipping city
PIN CodeOptionalBilling & Shipping pin code
Email IdOptionalZoho "Email"
HSNOptionalZoho "HSN/SAC" (defaults to 39232100 if blank)
💡 Notes: Header names case-insensitive match ho jaate hain aur kuch alternate spellings (jaise "Order ID"/"order id", "GSTIN"/"Customer GSTIN") bhi automatically detect ho jaate hain. Agar koi optional column missing hai to us cell ke liye blank/default value use ho jaayega — file reject nahi hogi. Sirf .xlsx ya .xls file accept hoti hai, first sheet hi read hoti hai.
